# Multiplying and dividing negative numbers (grade 7)

Multiplication by a positive number is repeated addition: 3 · (−2) = (−2) + (−2) + (−2) = −6.
So positive times negative is negative.

Why negative times negative is positive, as a pattern: count down the first factor and watch the product rise by 2 each time.
3 · (−2) = −6, 2 · (−2) = −4, 1 · (−2) = −2, 0 · (−2) = 0, so (−1) · (−2) = 2 and (−2) · (−2) = 4.

Why, using the distributive law: (−1) · (−2) + (−1) · 2 = (−1) · ((−2) + 2) = (−1) · 0 = 0.
Since (−1) · 2 = −2, the other term must be 2. So (−1) · (−2) = 2.

A story: losing 2 kg per week (−2). Three weeks ago (−3) you were 6 kg heavier: (−3) · (−2) = 6.

Division follows multiplication, because a ÷ b is the number that, multiplied by b, gives a: (−12) ÷ (−3) = 4 since 4 · (−3) = −12.
Rule: same signs give a positive result, different signs give a negative result. Zero is neither positive nor negative.

Common mistakes: applying "two negatives make a positive" to addition ((−3) + (−4) = −7, not 7);
confusing −3² = −9 with (−3)² = 9.
